# Сітка 9 — футбольні хрестики-нулики онлайн

**Грати:** https://football-party-games.onrender.com

Гра 1 на 1 з другом: поле 3×3, над стовпцями й біля рядків — клуби, збірні, трофеї, рекорди або позиції.
У свій хід обираєш клітинку і пишеш футболіста, який підходить під обидві умови.
Хто першим займе три клітинки в ряд — той переміг.

## Правила

- Перед грою той, хто створює кімнату, обирає час на хід: 15 / 20 / 30 / 45 / 60 с або **без ліміту**.
- Не встиг за час — хід переходить до суперника. Неправильна відповідь — теж.
- Один футболіст — **один раз за гру**. Повтор не зараховується (хід не втрачається, треба обрати іншого).
- Кожна сітка генерується так, що в ній гарантовано можна розставити 9 **різних** футболістів,
  і в кожній клітинці є щонайменше 3 правильні відповіді.
- Нічия: за згодою обох (пропозицію можна відхилити) або якщо у вільні клітинки вже нікого поставити.

## Режими

Режим обирає той, хто створює кімнату (за замовчуванням — звичайний).

| | 🟢 Легкий | 🟡 Звичайний | 🔴 Складний |
|---|---|---|---|
| Клуби | 15 топ-клубів | + Динамо, Шахтар | усі 26 |
| Збірні | 9 топових | + Україна | + Бельгія, Хорватія, Уругвай |
| Трофеї й рекорди | ЧС, ЛЧ, Євро, Золотий м'яч | + АПЛ, 300+ голів, 100+ матчів | + Копа, ЛЄ, Золотий бутс, 100+ передач |
| Позиції | так | так | так |
| Варіантів у клітинці | від 10, з них 6+ зірок (55+ мовних розділів Вікіпедії) | від 6, з них 4+ відомі (50+); для українських категорій — від 4 | 3–15, не більше 3 зірок |
| Особливість | | | щонайменше 4 з 6 категорій — нешаблонні (не з легкого режиму) |
| Кількість варіантів | видно | видно | прихована |

В усіх режимах зараховується будь-який правильний гравець з бази. З якого режиму з'являється категорія —
поле `level` у `server/data/categories.js`; пороги — `MODES` у `server/grid.js`.

## Кімната і взаємодія

- **Вийти з кімнати** можна будь-коли. Суперник побачить «… вийшов з гри», а кімната лишиться за ним —
  можна надіслати те саме посилання іншому другу. Коли виходять обидва — кімната видаляється.
- **Реванш:** після гри один пропонує, другий бачить «… хоче реванш» і приймає або виходить.
  У реванші починає інший гравець, рахунок серії зберігається.
- **Суперник зник** (закрив вкладку, пропав інтернет) — через 30 с можна забрати перемогу.
- **Повернутися до гри:** якщо закрив вкладку, на головній з'явиться кнопка повернення в кімнату.
- **Запрошення:** посилання на чужу кімнату спершу показує екран з ім'ям (можна змінити), а не кидає одразу в гру.
- **Реакції** 👍😂😮😡🔥👏 — видно обом гравцям.

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm start          # http://localhost:3000
```

### Хостинг

Гра задеплоєна на **Render** (безкоштовний план): https://football-party-games.onrender.com
Кожен push у гілку `main` на GitHub деплоїться автоматично (~2–3 хв). Налаштування — `render.yaml`.
Безкоштовний сервіс засинає після 15 хв без відвідувачів; перше відкриття після цього — ~30–60 с.
Кімнати живуть у пам'яті сервера, тож при деплої чи засинанні поточні ігри скидаються.

### Як дати доступ друзям з інтернету

- **Швидко, з твого комп'ютера:** `npx cloudflared tunnel --url http://localhost:3000` — дасть публічне посилання
  `https://….trycloudflare.com` (працює, поки запущені сервер і тунель; при кожному запуску адреса нова).
- **Постійно:** задеплоїти на Render / Railway / Fly.io або будь-який VPS (`npm install && npm start`, порт береться з `PORT`).
  Сервер тримає кімнати в пам'яті, тож потрібен один інстанс.

## База футболістів (~2500)

База **збирається скриптом** з відкритих джерел і лежить у `server/data/players.json`:

| Що | Звідки |
|---|---|
| клуби (включно з орендами), збірні, позиції, імена UA/RU/EN, рік народження | Wikidata |
| чемпіони світу / Європи, Копа Америка, ЛЧ, ЛЄ, Золотий м'яч / бутс, 100+ матчів за збірну | категорії uk/ru Вікіпедії |
| чемпіони АПЛ | en.wikipedia «List of Premier League winning players» |
| 300+ голів, 100+ передач, трофеї яких нема в категоріях | ручні дані: `server/data/players.js`, `server/data/manual-tags.js` |

У базу потрапляють гравці, що грали за один із клубів категорій і мають статтю щонайменше в 35 мовних
розділах Вікіпедії, зірки збірних (45+), а також гравці українських клубів і збірної (18+).

```bash
npm run build-players          # перезібрати базу (≈3–5 хв, Вікіпедія обмежує частоту запитів)
npm run fetch-photos           # фото нових гравців з Вікіпедії
npm run fetch-category-images  # герби, прапори, трофеї → public/img/categories/
npm test                       # автотест гри двома ботами
```

### Як виправити помилку в даних

Wikidata іноді містить неточності (наприклад, гравець підписав контракт, але за першу команду не грав).
У `server/data/manual-tags.js` можна додати або прибрати тег:

```js
'Pedro Porro': ['-BAR', '-MCI'],   // прибрати Барселону і Ман Сіті
'Gerd Müller': ['G300', 'BOOT'],   // додати 300+ голів і Золотий бутс
```

Потім `npm run build-players`.

## Структура

```
server/
  index.js                HTTP + Socket.IO, кімнати
  room.js                 логіка партії: ходи, таймер, перемога, нічия, реванш, вихід
  grid.js                 генерація сітки + перевірка «9 різних гравців» (паросполучення)
  data/players.json       зібрана база (не редагувати вручну)
  data/players.js         ручні дані про ~270 відомих гравців
  data/manual-tags.js     ручні виправлення тегів
  data/categories.js      категорії
public/                   інтерфейс (HTML/CSS/JS без збірки), img/categories — герби й трофеї
scripts/                  збирання бази, фото, картинки категорій, автотест
```

Фото гравців і зображення трофеїв — з Wikimedia Commons (вільні ліцензії CC); герби клубів — з англійської Вікіпедії.
